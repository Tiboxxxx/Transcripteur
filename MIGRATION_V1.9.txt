🚀 DÉMARRAGE EN 4 ÉTAPES
════════════════════════════════════════════════════════════════════════════

  1️⃣  OBTENIR CLÉ API (2 min)
      → https://aistudio.google.com/apikey
      → Créer API Key → Copier

  2️⃣  CONFIGURER (1 min)
      Option A : config.json
      {
        "gemini_api_key": "AIzaSy..."
      }

      Option B : Variable d'env
      export GEMINI_API_KEY="AIzaSy..."

  3️⃣  TESTER (30 sec)
      source venv/bin/activate
      python3 test_gemini.py
      
      Résultat : "Test Result: PASSED"

  4️⃣  UTILISER (identique à avant)
      python3 app.py run --name "ma_video" --duration 120

⚡ PERF & COÛTS
════════════════════════════════════════════════════════════════════════════

  Performance :
    • Whisper : ~30s / 10min audio (GPU)
    • Gemini : ~5-10s API call
    • Total : ~40s / 10min audio ⚡

  Coûts :
    • Gratuit jusqu'à 1M tokens/jour
    • ~1000 transcriptions/jour gratuites ✅
    • Modèle : Gemini 1.5 Flash (ultra rapide)


🛡️  SÉCURITÉ IMPORTANT
════════════════════════════════════════════════════════════════════════════

  ⚠️  NE PAS COMMITTER config.json avec clé API

  Faire :
    echo "config.json" >> .gitignore
    export GEMINI_API_KEY="..."

  Ne PAS faire :
    git add config.json  # ❌
    echo 'AIzaSy...' en dur  # ❌


📞 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

  "API key not valid"
    → Vérifier clé commence par "AIza"
    → Régénérer clé en Google AI Studio

  "enable_gemini_enrichment: false"
    → Éditer config.json : "enable_gemini_enrichment": true

  Enrichissement silencieusement échoué
    → C'est ok! Continu sans enrichissement
    → Vérifier GEMINI_API_KEY
