# Transcripteur Local V1.9 - Intégration Gemini

## 🎯 Changements majeurs

### Ajout de l'enrichissement Gemini
- **Avant V1.9** : Transcription locale uniquement avec Whisper
- **V1.9** : Transcription Whisper + enrichissement automatique avec Gemini AI

### Nouvelles fonctionnalités

1. **Enrichissement automatique** via Gemini API
   - Résumé en 2-3 phrases
   - Extraction de mots-clés (max 5)
   - Identification des sujets traités
   - Analyse du sentiment (positif/neutre/négatif)
   - Score de qualité (0-100)

2. **Intégration frontmatter markdown**
   - Les enrichissements Gemini sont stockés dans le frontmatter YAML
   - Section "Résumé" ajoutée au début du markdown enrichi
   - Métadonnée `enriched_by: gemini-pro-latest` pour traçabilité

3. **Configuration flexible**
   - Clé API stockée dans `config.json` ou variable d'env `GEMINI_API_KEY`
   - Option `enable_gemini_enrichment` pour activer/désactiver (défaut: true)
   - Si Gemini échoue, le pipeline continue sans enrichissement

## ⚡ Performance

- **Whisper local** : ~30s pour 10min d'audio (GPU)
- **Gemini enrichissement** : ~5-10s (API call)
- **Total** : ~35-40s par transcription

## 🛡️ Sécurité

⚠️ **Important** : La clé API Gemini dans `config.json` n'est pas chiffrée. Recommendations :
- Ne pas committer `config.json` avec clé API dans git
- Utiliser plutôt une variable d'env `GEMINI_API_KEY`
- Ajouter `config.json` à `.gitignore` si vous versionnez

## 📌 Utilisation

Identique aux versions précédentes, enrichissement automatique :

```bash
# Enregistrement + transcription avec enrichissement Gemini
source venv/bin/activate
python3 app.py run --name "ma_reunion" --duration 300

# Ou transcription d'un fichier existant
python3 app.py transcribe --file captures/ma_reunion.wav
```

## ✅ Backward compatibility

- Venv Python créé (dépendances isolées)
- Code Python 3.10+
- Pas d'impact sur formats d'export
- Peut désactiver Gemini avec `"enable_gemini_enrichment": false`

## 🐛 Dépannage

### "Aucune clé Gemini API trouvée"
- Vérifier `config.json` > `gemini_api_key` est remplie
- Ou définir `export GEMINI_API_KEY="..."`

### "Erreur configuration Gemini"
- Vérifier que la clé API est valide
- Tester avec `python3 -c "import google.generativeai; print('OK')"`

### Gemini API timeout
- Fichier audio très long? Tronquer le texte avant Gemini (déjà limité à 2000 chars)
- Retry automatique disponible dans une future version
