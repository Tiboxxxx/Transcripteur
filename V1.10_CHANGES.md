# V1.10 — Mode "zéro friction" (2026-07-06)

Objectif : lancer l'enregistrement d'une vidéo/d'un podcast sans rien décider,
et retrouver une note titrée dans Obsidian.

## Nouveau flux recommandé

```bash
./transcripteur          # démarre l'enregistrement immédiatement
# ... regarde ta vidéo / écoute ton podcast ...
# CTRL+C une fois → transcription + export Obsidian automatiques
```

## Nouveautés

- **`--name` optionnel** (`record` et `run`) : nom horodaté automatique
  (`capture_2026-07-06_14h32`) si absent.
- **Titre auto Gemini** : si l'enrichissement est activé
  (`enable_gemini_enrichment: true`) et qu'aucun `--title` n'est fourni,
  le titre proposé par Gemini est utilisé pour le frontmatter et les notes
  auto-nommées sont renommées d'après ce titre.
- **Anti-écrasement** : plus jamais de perte silencieuse — un suffixe `_2`,
  `_3`… est ajouté si un fichier audio ou une note du même nom existe déjà.
- **Temps écoulé affiché** pendant l'enregistrement (`⏺ Enregistrement... 12:34`).
- **Détection de silence** : après ~12 s, si aucun signal audio n'est capté,
  un avertissement s'affiche immédiatement (mauvaise source, volume coupé…)
  au lieu de le découvrir à la fin.
- **`./transcripteur` sans argument** = `run` direct ; les autres usages
  (`./transcripteur check`, `./transcripteur transcribe ...`) sont inchangés.
  Le script utilise désormais `venv/` (environnement complet avec google-genai).

## Tableau de bord web (V1.10, suite)

```bash
./transcripteur-web      # puis ouvrir http://localhost:8765
```

- Bouton **⏺ Enregistrer / ⏹ Arrêter et transcrire** (équivalent CTRL+C, tout
  le pipeline suit automatiquement : transcription → Gemini → Obsidian).
- Timer en direct, alerte silence, bannière de fin avec le titre de la note.
- Tuiles : **tokens Gemini restants** (jauge), coût estimé, nombre de
  transcriptions, durée capturée.
- **Notes récentes** avec durée audio réelle et date de modification.
- Interrupteur enrichissement Gemini (modifie config.json).
- Journal des dernières lignes du pipeline.
- Fichiers : `web_app.py` (serveur Flask, localhost uniquement) +
  `static/index.html` (aucune ressource externe, mode sombre automatique).
- Pourquoi pas Docker : la capture audio (PulseAudio) et le GPU doivent rester
  sur l'hôte ; un conteneur ajouterait de la complexité sans bénéfice.
- Bouton **« Ouvrir ↗ »** par note : lien `obsidian://` qui ouvre la note
  directement dans Obsidian (affiché si la note existe dans le vault).
- **Remise à zéro mensuelle** du compteur de tokens Gemini : le mois courant est
  stocké dans `logs/gemini_stats.json` ; au changement de mois, tokens/coût/
  compteur repartent de zéro (aligné sur le quota free tier mensuel).
